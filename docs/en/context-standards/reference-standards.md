## 2. Deep-Dive Standard Citations

### 1. Requirements Engineering (ISO/IEC/IEEE 29148:2018)
- **Standard**: *Systems and software engineering — Life cycle processes — Requirements engineering*.
- **Publisher**: IEEE Standards Association / International Organization for Standardization.
- **Core Principle Applied**: Requirements must be atomic, unambiguous, verifiable, prioritized, and traceable.

### 2. OMG Unified Modeling Language (OMG UML v2.5.1)
- **Standard**: *OMG Unified Modeling Language (OMG UML), Version 2.5.1*.
- **Publisher**: Object Management Group (OMG), 2017.
- **Core Principle Applied**: Precise visual syntax for structural relationships (inheritance, composition, aggregation) and behavioral sequences.

### 3. The C4 Model for Visualising Software Architecture
- **Author**: Simon Brown (2020).
- **Core Principle Applied**: Zoomable abstraction layers from high-level enterprise system contexts down to deployment containers and components.

### 4. arc42 Architecture Communication Framework
- **Authors**: Dr. Gernot Starke & Dr. Peter Hruschka.
- **Core Principle Applied**: Complete, pragmatic 12-section architecture documentation answering "Why", "What", and "How".

### 5. OpenAPI Specification (OAS 3.1.0)
- **Publisher**: OpenAPI Initiative / Linux Foundation (2021).
- **Core Principle Applied**: Full JSON Schema 2020-12 alignment for declarative API contracts and client generation.

### 6. Nielsen Norman Group Usability Standards
- **Authors**: Jakob Nielsen & Rolf Molich (1990, 1994, 2020).
- **Core Principle Applied**: 10 heuristic rules governing human-computer interaction and defect severity classification.

### 7. W3C Web Content Accessibility Guidelines (WCAG 2.2)
- **Publisher**: World Wide Web Consortium (W3C Recommendation, 2023).
- **Core Principle Applied**: Perceivable, Operable, Understandable, and Robust user interfaces accessible to all humans and assistive tools.

### 8. Google Developer Documentation Style Guide
- **Publisher**: Google Open Source Documentation Team.
- **Core Principle Applied**: Clear, direct, audience-focused technical writing with minimal cognitive overhead.

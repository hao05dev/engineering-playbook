# AI Software Engineering Knowledge Base

Kho tri thức kỹ thuật phần mềm chuẩn hóa dành cho lập trình viên và các tác nhân AI (AI Coding Agents). Cung cấp hướng dẫn chi tiết, biểu mẫu thực thi, bộ tiêu chuẩn kỹ thuật quốc tế (IEEE 29148, OMG UML, C4 Model, arc42, OpenAPI 3.1, NN/g Usability, Google Doc Standards) và các tài liệu chuyên sâu về công nghệ (Next.js, C# .NET) được cấu trúc thành **4 Trụ cột chính**.

Hỗ trợ song ngữ đầy đủ: **English** & **Tiếng Việt**.

## 📚 Cấu Trúc Danh Mục 4 Trụ Cột

### 🎯 Trụ cột 1: AI-SDLC & Giao Thức Hợp Tác
- **01 — AI-SDLC Playbook**: Quy trình 11 bước phát triển phần mềm toàn diện cùng AI.
- **11 — Giao thức Hợp tác AI**: Vòng đời 6 giai đoạn, phân loại thông tin (`[CONFIRMED]`, `[ASSUMPTION]`) & hội đồng AI Reviewer.
- **12 — Tệp Ngữ cảnh & Tiêu chuẩn**: Bộ 10 tệp ngữ cảnh AI (`AGENTS.md`, `DOMAIN.md`), thư viện prompt mẫu & ma trận tiêu chuẩn quốc tế.

### 📐 Trụ cột 2: Phân Tích Hệ Thống & Kiến Trúc
- **02 — Phân tích Nghiệp vụ (Domain)**: Phân tích nghiệp vụ, DDD, ngôn ngữ chung & bất biến.
- **03 — Kỹ thuật Yêu cầu (IEEE 29148)**: Kỹ thuật yêu cầu chuẩn ISO/IEC/IEEE 29148:2018 (BRD, PRD, SRS).
- **04 — Phân tích Hệ thống & UML**: Mô hình hóa hệ thống chuẩn OMG UML 2.5.1 (Use Case, Sequence, State, Class).
- **05 — Kiến trúc Phần mềm (C4/arc42)**: Kiến trúc phần mềm theo C4 Model & khung chuẩn arc42.
- **06 — Quyết định Kiến trúc (ADR)**: Nhật ký quyết định kiến trúc chuẩn MADR 3.0.0.

### ⚡ Trụ cột 3: Kỹ Thuật Fullstack & Thiết Kế
- **07 — Kỹ thuật Cơ sở Dữ liệu**: Thiết kế CSDL quan hệ chuẩn 3NF, chiến lược index & Flyway migrations.
- **08 — Kỹ thuật API (OpenAPI 3.1)**: Thiết kế RESTful API, hợp đồng OpenAPI 3.1 & Idempotency.
- **09 — Kỹ thuật UI / UX (NN/g)**: Trải nghiệm người dùng theo NN/g, 4 trạng thái UI & chuẩn tiếp cận WCAG 2.2 AA.
- **10 — Kỹ thuật Tài liệu (Google)**: Kỹ thuật tài liệu Docs-as-Code theo chuẩn Google Developer Docs.

### 🚀 Trụ cột 4: Công Nghệ & Frameworks
- **Next.js Fullstack Engineering**: App Router, React Server Components (RSC), Server Actions, Caching 4 tầng, Form UX & Auth.
- **C# .NET Enterprise Engineering**: .NET 8/9 LTS, Clean Architecture, DDD, ASP.NET Core Minimal APIs, EF Core & Dapper, Async/CQRS & Testcontainers.
